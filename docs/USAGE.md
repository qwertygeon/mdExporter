## 기본 사용법

```
mdexport <input.md> [옵션]
```

`<input.md>` 는 변환할 Markdown 파일 경로다. 소스에서 빌드해 쓰는 경우 `mdexport` 대신 `node dist/cli.js` 로 실행한다.

옵션 없이 실행하면 입력 파일과 같은 폴더에 HTML 과 PDF 를 모두 생성한다.

```bash
mdexport 문서.md
# → 문서.html, 문서.pdf 생성
```

## 옵션

### --format

`-f, --format <format>` — 생성할 포맷을 지정한다.

| 값 | 결과 |
|---|---|
| `both` (기본) | HTML 과 PDF 모두 |
| `html` | HTML 만 (브라우저 불필요) |
| `pdf` | PDF 만 |

```bash
mdexport 문서.md -f html
```

### --theme

`-t, --theme <path>` — 사용할 테마 CSS 파일 경로. 지정하지 않으면 내장 기본 테마를 쓴다.

```bash
mdexport 문서.md -t my-theme.css
```

테마 작성·커스터마이즈는 [테마 가이드](THEMING.md) 참조.

### --title

`--title <title>` — HTML 산출물의 `<title>` 값. 지정하지 않으면 입력 파일명(확장자 제외)을 쓴다.

```bash
mdexport report.md --title "월간 보고서"
```

### --out-dir

`-o, --out-dir <dir>` — 산출물을 저장할 디렉터리. 지정하지 않으면 입력 파일과 같은 폴더에 저장한다. 폴더가 없으면 생성된다.

```bash
mdexport report.md -o build/
```

## 출력 규칙

- 산출물 파일명은 입력 파일명을 따른다: `report.md` → `report.html`, `report.pdf`.
- 저장 위치는 `--out-dir` 지정 시 그 폴더, 아니면 입력 파일과 같은 폴더.
- 성공 시 생성된 파일 경로가 `✓ <경로>` 형태로 출력된다.

## PDF 페이지 설정

현재 PDF 는 아래 고정 설정으로 생성된다:

- 용지: A4
- 여백: 상하 18mm, 좌우 15mm
- 배경 인쇄: 켜짐 (표 헤더·콜아웃·코드 박스 배경이 인쇄에 포함됨)

페이지 나눔은 테마의 인쇄 규칙을 따른다 — 표·코드 블록·콜아웃은 페이지 경계에서 잘리지 않게 처리되며, 한 페이지보다 큰 요소는 예외적으로 나뉜다.

## 내용 불변 원칙

변환은 원본 Markdown 에 **스타일만 입힌다.** 문구·구조를 바꾸지 않으며, 자동 인용부호 치환·자동 링크화 같은 원문 변형 처리를 하지 않는다. 산출물의 텍스트 내용은 원본과 일치한다.

## 트러블슈팅

| 증상 | 원인 · 해결 |
|---|---|
| PDF 생성 시 브라우저 관련 오류 | Chromium 미설치 — `npx playwright install chromium` 로 1회 설치 |
| 한글이 기본 고딕으로 나옴 | 네트워크 차단으로 웹폰트(Pretendard) 로드 실패 → 시스템 폰트로 폴백된 것. 온라인에서 재시도 |
| 표·코드 박스 배경이 PDF 에서 안 보임 | 기본 설정은 배경 인쇄 켜짐 — 커스텀 테마에서 배경을 제거하지 않았는지 확인 |
| 스타일이 안 먹음 | `--theme` 경로가 실행 위치 기준으로 유효한지 확인 |
| 표·코드가 페이지 경계에서 잘림 | 요소가 한 페이지보다 크면 불가피 — 내용을 나누거나 테마 폰트 크기를 조정 |
