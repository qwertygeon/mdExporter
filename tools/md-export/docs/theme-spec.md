## 디자인 원칙

- **시인성의 80%는 타이포그래피**: 폰트·줄폭·줄간격이 우선, 장식은 최소한의 액센트 컬러 1색(파랑 계열)으로 절제한다.
- **완결적 스타일시트**: 도구 기본 스타일에 의존하지 않고 모든 요소를 자체 정의한다 (설계 문서 ADR-3).
- **화면·인쇄 공용**: 기본 규칙은 화면(HTML) 기준으로 정의하고, 인쇄 차이만 `@media print` 로 오버라이드한다.

## 타이포그래피

| 항목 | 값 | 이유 |
|---|---|---|
| 폰트 스택 | `Pretendard Variable` → `Pretendard` → `Apple SD Gothic Neo` → `Noto Sans KR` → 시스템 sans | 한글 시인성 기준 1순위 Pretendard(웹폰트), 오프라인·미로드 시 OS 별 고품질 한글 폰트로 폴백 |
| 웹폰트 로드 | jsdelivr CDN 의 dynamic-subset `@import` | 사용 글리프만 서브셋 로드 — 전체 폰트 대비 전송량 절감 |
| 본문 크기/줄간격 | 15px / 1.75 | 한글 본문 가독 기준. 인쇄 시 10.5pt 로 축소(`@media print`) |
| 본문 폭 | `max-width: 860px` 중앙 정렬 | 줄폭이 과도하면 시선 이동 피로 — 화면에서 읽기 폭 제한. 인쇄 시 해제(페이지 여백이 폭을 결정) |
| 줄바꿈 | `word-break: keep-all` | 한글 단어 중간 꺾임 방지 — 어절 단위 줄바꿈 |

## 헤딩 위계

| 레벨 | 스타일 | 의도 |
|---|---|---|
| h1 | 1.9em·굵은 자간 축소 + **하단 3px 액센트 라인** | 문서 제목 1개 전제 — 표지선 역할 |
| h2 | 1.35em + **좌측 5px 액센트 바** | 절(섹션) 구분을 스캔만으로 파악되게 — 목차 없는 훑어읽기 지원 |
| h3 | 1.08em·액센트 진한 색 텍스트 | 소절은 크기 대신 색으로 구분 — 위계 유지하며 수직 공간 절약 |

## 표

- 전체 폭·`border-collapse` — 셀 경계 이중선 제거.
- 헤더 행: 옅은 파랑-회색 배경(`#eef2f9`) + 굵은 글씨 — 데이터와 머리글 즉시 구분.
- 본문 행: 짝수 행 zebra 배경(`#f8fafc`) — 넓은 표에서 행 추적 보조.
- 폰트 0.94em — 표는 밀도가 높으므로 본문보다 살짝 축소.

## 코드

- 인라인 코드: 옅은 배경 + 남색 텍스트 + 라운드 — 본문 속에서 식별되되 튀지 않게.
- 코드 블록: 옅은 회색 박스 + 1px 테두리 + 8px 라운드 — 명도 대비를 약하게 유지(인쇄 시 잉크 절약·눈부심 방지).
- 폰트: SF Mono → JetBrains Mono → Menlo → Consolas 폴백 모노스페이스.

## 인용 블록 — 콜아웃

`>` 인용을 **파란 콜아웃 카드**(옅은 파랑 배경 + 좌측 5px 바 + 우측 라운드)로 렌더링한다.
기술 문서에서 `>` 는 대부분 근거·주의·보충 노트로 쓰이므로, 인용보다 "주목 박스"가 의미에 부합한다.

## 페이지 나눔 (PDF)

| 규칙 | 대상 | 이유 |
|---|---|---|
| `break-after: avoid` | h2·h3 | 헤딩만 페이지 끝에 남고 본문이 다음 페이지로 넘어가는 고아 헤딩 방지 |
| `break-inside: avoid` | 표·코드 블록·콜아웃 | 자기완결 단위가 페이지 경계에서 반토막 나는 것 방지 (한 페이지 초과 요소는 예외적으로 잘림) |
| 페이지 여백 | `--pdf-options` 의 A4·상하 18mm·좌우 15mm | 여백은 CSS 가 아닌 인쇄 옵션이 보유 — 테마와 페이지 설정의 관심사 분리 |

## 커스터마이즈 포인트

색은 `:root` CSS 변수로 모여 있다 — 브랜드 적용 시 이 블록만 교체한다.

| 변수 | 역할 |
|---|---|
| `--ink` | 본문 텍스트 색 |
| `--muted` | 보조 텍스트 색 |
| `--accent` / `--accent-dark` | 액센트(헤딩 라인·바·링크) / 진한 변형(h3·인쇄 링크) |
| `--line` | 테두리·구분선 |
| `--bg-soft` / `--bg-code` | zebra 행·코드 블록 배경 |

폰트 교체는 `body` 의 `font-family` 와 상단 `@import` 를 함께 수정한다.
